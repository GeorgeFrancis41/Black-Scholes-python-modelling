## Black-Scholes-python-modelling
# Overview
Using the Black-Scholes model on a European option to predict when to buy and sell along with comparing with S&amp;P 500 returns.

# Features
- Uses the Black-Scholes model and derivatives to help predict European option prices
- Compare the data obtained with S&P 500 data

# Tools & libraries
- Python
- yFinance
- Pandas
- Matplotlib
- Numpy
- Scipy

# Use
- Run the code and edit parameters to see what values you can obtain, such as editing the limits for delta or the beginning portfolio amount.

# Future improvements
- I hope to add a way to optimise the parameters so that it can maximise the returns and, eventually, drastically outpreform the S&P
